# 2026-10-09

## API keys are tied to Keycloak's authorization model at issue

The API key plugin checks every requested scope against Keycloak's authorization model when a key is minted, so a scope that parses does not mint without a matching resource, scope and permission there, and Usher-native scope names cannot be minted until that check is replaced. Refusing DENY at creation is a plugin change requested with the Usher scope format, not before. A key's lifetime is deployment-wide, fixed at issue and one year when unset, and an invalid key's check returns no scope.

## The first publish is the Arranger adapter's last step

The adapter is built and reviewed and merges once both packages are published; the admin model's spelling is Canadian throughout.
